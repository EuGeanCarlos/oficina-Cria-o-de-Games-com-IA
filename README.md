# 🎮 Prompts para Criação de Games com IA

Este repositório reúne **prompts prontos para criação de jogos simples usando Inteligência Artificial**, com foco em **HTML, CSS, JavaScript e HTML Canvas**.

A proposta é permitir que estudantes, professores e iniciantes em programação consigam criar pequenos jogos diretamente no navegador, utilizando ferramentas de IA generativa como apoio durante o desenvolvimento.

---

## 🚀 Objetivo

O objetivo deste projeto é demonstrar como a **engenharia de prompts** pode ser utilizada para transformar ideias em protótipos de jogos funcionais.

A partir de uma descrição em linguagem natural, a IA pode gerar:

* estrutura HTML;
* estilização com CSS;
* lógica utilizando JavaScript;
* movimentação de personagens;
* sistemas de pontuação;
* vidas;
* obstáculos;
* itens coletáveis;
* fases;
* telas de vitória e derrota;
* mecânicas educativas.

Os jogos foram pensados principalmente para atividades introdutórias com crianças e adolescentes, permitindo que os participantes aprendam conceitos básicos de:

* programação;
* lógica computacional;
* desenvolvimento de jogos;
* criatividade;
* inteligência artificial;
* elaboração e melhoria de prompts.

---

# 🧠 Como funciona?

Cada jogo começa com um **prompt**, ou seja, uma instrução enviada para uma Inteligência Artificial.

Exemplo:

```text
Crie um jogo simples em HTML Canvas e JavaScript.

O personagem principal é um pequeno robô.

Ele deve andar para esquerda e direita usando as setas do teclado
e pular utilizando a tecla espaço.

O cenário deve possuir plataformas, cristais para coletar
e pequenos monstros como obstáculos.

O jogador vence quando coletar todos os cristais
e chegar até o portal.

Mostre pontuação e vidas na tela.

Coloque todo o código em um único arquivo HTML
para abrir diretamente no navegador.
```

A IA poderá então produzir um jogo funcional utilizando:

```text
HTML
CSS
JavaScript
Canvas
```

# 🎯 Estrutura básica de um bom prompt

Para gerar jogos melhores, recomendamos que o prompt apresente algumas informações importantes.

## 1. Nome do jogo

Exemplo:

```text
Crie um jogo chamado "Turbo Robô".
```

---

## 2. Personagem

Explique quem o jogador controla.

Exemplo:

```text
O jogador controla um pequeno robô.
```

---

## 3. Controles

Informe quais teclas serão utilizadas.

Exemplo:

```text
Use as setas esquerda e direita para movimentar
e a tecla espaço para pular.
```

---

## 4. Objetivo

Defina claramente como o jogador vence.

Exemplo:

```text
O jogador deve coletar 5 cristais
e chegar até o portal.
```

---

## 5. Obstáculos

Informe quais elementos dificultam o jogo.

Exemplo:

```text
Adicione pequenos monstros, pedras e buracos
como obstáculos.
```

---

## 6. Pontuação

Defina como os pontos serão conquistados.

Exemplo:

```text
Cada cristal coletado vale 10 pontos.
```

---

## 7. Sistema de vidas

Exemplo:

```text
O jogador começa com 3 vidas
e perde uma vida ao tocar em um inimigo.
```

---

## 8. Final do jogo

Exemplo:

```text
Adicione uma tela de vitória,
uma tela de Game Over
e um botão "Jogar novamente".
```

---

## 9. Tecnologia utilizada

Para facilitar a execução durante oficinas, recomendamos solicitar:

```text
Coloque HTML, CSS e JavaScript
em um único arquivo HTML.

O jogo deve funcionar diretamente no navegador
sem necessidade de instalar bibliotecas.
```

# 💡 Processo de criação

Uma das ideias principais do projeto é mostrar que o desenvolvimento não precisa terminar no primeiro prompt.

O jogo pode ser melhorado através de novas solicitações.

### Prompt inicial

```text
Crie um jogo onde um robô coleta cristais.
```

### Segunda solicitação

```text
Agora adicione três vidas ao jogador.
```

### Terceira solicitação

```text
Adicione monstros que se movimentam pelas plataformas.
```

### Quarta solicitação

```text
Adicione um portal que só seja liberado
quando todos os cristais forem coletados.
```

### Quinta solicitação

```text
Melhore o visual do personagem e das plataformas.
```

Esse processo mostra que a criação de um jogo com IA pode ser **iterativa**.

```text
IDEIA
  ↓
PROMPT
  ↓
CÓDIGO
  ↓
TESTE
  ↓
NOVO PROMPT
  ↓
MELHORIA
  ↓
NOVO TESTE
```

# 🖥️ Como executar os jogos

A maioria dos exemplos pode funcionar sem nenhuma instalação adicional.

### 1. Crie um arquivo

```text
jogo.html
```

### 2. Cole o código gerado pela IA.

### 3. Salve o arquivo.

### 4. Abra o arquivo no navegador.

Exemplo:

```text
Google Chrome
Microsoft Edge
Firefox
```

O jogo será executado diretamente no navegador.

# 🤖 IA como ferramenta de criação

A Inteligência Artificial deve ser utilizada como **ferramenta de apoio ao desenvolvimento**.

O estudante continua sendo responsável por:

* imaginar o jogo;
* definir as regras;
* criar o objetivo;
* escolher personagens;
* testar;
* encontrar erros;
* propor melhorias;
* modificar o projeto.

Assim, a atividade também desenvolve criatividade e raciocínio lógico.

# ⚠️ Importante

O código gerado por Inteligência Artificial pode apresentar erros.

Por isso, sempre:

```text
GERAR
   ↓
TESTAR
   ↓
OBSERVAR
   ↓
CORRIGIR
   ↓
TESTAR NOVAMENTE
```

Encontrar e corrigir problemas também faz parte do processo de programação.
